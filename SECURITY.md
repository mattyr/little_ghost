# Security Policy

Security fixes are provided for the latest released version of LittleGhost.

Please report suspected vulnerabilities through
[GitHub's private vulnerability reporting](https://github.com/mattyr/little_ghost/security/advisories/new)
instead of opening a public issue. A useful report includes the affected
version, expected impact, reproduction details, and any known mitigations.

The maintainer will review the report and coordinate disclosure as practical.
